# RestEye · 眸息

RestEye（眸息）是一款简洁、跨平台的护眼提醒工具。它以 20-20-20 规则为基础，帮助你在工作与休息之间建立稳定节奏，减少长时间注视屏幕带来的眼睛疲劳。

Android、Windows 和 macOS 共享一致的 Material 3 界面与计时体验，并使用各平台的原生通知、托盘或菜单栏能力。

## 主要功能

- 按 20-20-20 规则提醒工作与休息，也可以自定义持续时间
- 清晰显示已工作、已休息时间和当前阶段
- 支持直接开始休息、跳过休息和开始下一轮工作
- 可配置未休息、未工作的重复提醒与超时处理
- 通过系统原生通知直接执行计时操作
- 支持锁屏暂停工作计时
- 统计每天的工作时长、休息时长和完成休息次数
- 支持浅色、深色、跟随系统主题，以及中文和英文
- Windows 支持系统托盘，macOS 支持菜单栏驻留

## 支持平台

- Android
- Windows
- macOS

## Android 使用提示

为了让 RestEye 在后台按时提醒，建议在系统设置中：

1. 授予 RestEye 通知权限。
2. 将电池或省电策略设为“不限制”或“无限制”。
3. 根据需要开启“弹窗通知”“悬浮通知”或同类选项。

不同 Android 版本和手机厂商使用的设置名称可能略有差异。

## 隐私

RestEye 不需要账号。计时设置与统计数据默认只保存在本机，不上传到云端。
